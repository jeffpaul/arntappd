# Arntappd

A planned mobile web experience for photographing a beer menu, confirming
Untappd matches, and comparing personal, friends' and global ratings.

## Implementation recovery required

The application described earlier in the project conversation was not present
in the restored workspace on October 17, 2026. This repository currently
preserves the MVP and post-MVP backlog, not a runnable application. Recovering
and committing the source is the first MVP blocker.

See [the backlog](docs/backlog/README.md) for 7 MVP issues and 8 post-MVP issues,
including Render deployment, live-provider validation, Untappd sign-in, physical
iPhone testing, shelf/tap-handle recognition, and live camera overlays.

Issue bodies are prepared locally. Their presence in this repository does not
mean GitHub issues were created. The backlog includes a resumable publishing
script for when authenticated GitHub API access is available.
